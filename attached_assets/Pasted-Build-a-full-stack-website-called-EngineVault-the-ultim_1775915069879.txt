Build a full-stack website called "EngineVault" — the ultimate online resource for automotive engine builders. This is a high-traffic content and tools platform targeting both DIY hobbyists and professional engine builders/machine shops. The goal is maximum organic search traffic and ad revenue.

---

TECH STACK
- Frontend: React (Vite) with React Router for multi-page navigation
- Backend: Node.js + Express API server
- Database: SQLite (via better-sqlite3) for specs database and user submissions
- Styling: Plain CSS with CSS variables (no Tailwind) — clean, dark-capable, professional automotive aesthetic
- No authentication required for v1 — all tools are free and open
- Mobile-first responsive design

---

DESIGN SYSTEM
- Color palette: Deep charcoal (#1a1a1a) headers/nav, white content areas, orange accent (#E85D04) for CTAs and highlights — feels like a performance shop, not a generic blog
- Typography: System font stack — clean and fast-loading
- Navigation: Sticky top nav with logo, main sections dropdown, and a persistent "Calculators" button in orange
- Footer: Links to all major sections, brief "About EngineVault" blurb, disclaimer that all specs should be verified against factory service manuals

2. ENGINE SPECS DATABASE (/specs)
   - Landing page shows a grid of engine families: GM LS Series, GM Small Block (SBC), GM Big Block (BBC), Ford Small Block, Ford Big Block, Ford Coyote/Modular, Mopar Small Block, Mopar Big Block, Toyota 2JZ, Honda B/K Series
   - Each engine family has its own page (/specs/ls-series, /specs/sbc, etc.)
   - Each engine page contains a tabbed layout with these data sections:
     a) TORQUE SPECS — bolt-by-bolt table: fastener location, torque value (ft-lbs AND Nm), sequence notes, thread lubricant notes (dry/ARP lube/motor oil), whether it's a torque-to-yield bolt
     b) CLEARANCE SPECS — main bearing clearance, rod bearing clearance, piston-to-wall clearance, ring end gap (top/second/oil), valve stem-to-guide clearance, camshaft bearing clearance — shown as factory spec range AND performance build range
     c) DIMENSIONS — bore, stroke, displacement, rod length, rod ratio, compression height, deck height, firing order, cam journal diameter
     d) IDENTIFICATION — casting number lookup table (block castings, head castings), VIN decoder guide, date code explanation
   - Specs data is stored in SQLite. Pre-populate with complete data for at minimum: LS1, LS2, LS3, LS6, LS7, LQ4, LQ9 (Gen III/IV LS family), Chevy 350 (all variants), Chevy 454, Ford 302 Windsor, Ford 351 Windsor, Ford 5.0 Coyote
   - Each spec page has a "Print / Save as PDF" button for shop use
   - Each page has a clear disclaimer: "Always verify specs against your factory service manual. Specs may vary by production year, casting, and application."

3. CALCULATOR SUITE (/calculators)
   - Landing page grid showing all 8 calculators with description cards
   - Build each calculator as its own page with real-time calculation (updates as user types)

   CALCULATOR 1: Engine Displacement (/calculators/displacement)
   - Inputs: bore (inches or mm toggle), stroke (inches or mm), number of cylinders
   - Outputs: displacement in cubic inches AND liters AND cc, with visual cylinder diagram
   - Also show: piston speed at a user-entered RPM, mean piston speed
   - Bonus: "What common engine is this close to?" — match against a lookup table

   CALCULATOR 2: Compression Ratio — Static AND Dynamic (/calculators/compression-ratio)
   - STATIC inputs: bore, stroke, gasket bore, gasket thickness, deck height, piston dish/dome volume (cc), head chamber volume (cc)
   - STATIC output: compression ratio with color-coded fuel octane recommendation
   - DYNAMIC inputs: add intake valve closing point (degrees ABDC), atmospheric pressure
   - DYNAMIC output: dynamic compression ratio with explanation of why this matters
   - Side-by-side static vs dynamic comparison panel
   - Explain in plain English how dynamic CR is what actually causes detonation

   CALCULATOR 3: Piston Ring End Gap (/calculators/ring-gap)
   - Inputs: bore size, ring type (top compression, second compression, oil), application type (naturally aspirated street, NA performance, forced induction street, full race)
   - Output: recommended gap range in both inches and mm with color-coded OK/too-tight/too-loose zones
   - Bonus: shows what happens if gap is too small (land damage from heat expansion) vs. too large (blowby, oil consumption)

   CALCULATOR 4: Camshaft Duration Converter (/calculators/cam-duration)
   - Inputs: duration at advertised (with user-entered checking clearance), duration at .050", lift at the valve, rocker arm ratio
   - Outputs: duration at .004" (advertised), at .050", at .200" — all converted
   - Also: lobe lift from valve lift + rocker ratio, gross valve lift from lobe lift + rocker ratio
   - Explanatory text about why cam manufacturers measure differently and how to compare specs

   CALCULATOR 5: Connecting Rod Ratio (/calculators/rod-ratio)
   - Inputs: stroke, rod length
   - Output: rod ratio with a gauge showing where it falls on a spectrum (low 1.4 — ideal 1.7-1.8 — high 2.0+)
   - Explain what rod ratio affects: piston dwell, side loading, piston speed, friction
   - Compare common engine rod ratios in a table (e.g., Chevy 350 = 1.68, LS1 = 1.70, Honda B16 = 1.70)

   CALCULATOR 6: Torque & Horsepower Converter (/calculators/hp-torque)
   - Bidirectional: enter HP + RPM → get torque. Enter torque + RPM → get HP
   - Formula explanation: HP = (Torque × RPM) / 5252
   - Show crossover point at 5252 RPM on a visual chart
   - Unit conversion: ft-lbs ↔ Nm ↔ kg-m

   CALCULATOR 7: Engine Build Cost Estimator (/calculators/build-cost)
   - User selects engine platform (dropdown: LS swap, SBC 350, SBC 383 stroker, Ford 302, Ford 351, 2JZ, Honda K-series)
   - User selects build level: Stock Rebuild / Mild Street Performance / Aggressive Street / Full Race
   - User selects: New vs Remanufactured vs Core/Junkyard starting point
   - Output: itemized cost breakdown table with low/high ranges for:
     * Core engine / junkyard donor
     * Machine shop work (bore/hone, deck, crank grind, valve job, balance, assembly)
     * Pistons & rings
     * Bearings (main, rod, cam)
     * Gasket set
     * Timing kit
     * Camshaft & lifters (if applicable)
     * Oil pump
     * Bolts/studs
     * Assembly lube & supplies
   - Total range at bottom: "Estimated total parts + machine work: $X,XXX – $X,XXX"
   - Note: "Labor for removal/installation not included. Machine shop prices vary significantly by region."

   CALCULATOR 8: Piston Speed Calculator (/calculators/piston-speed)
   - Inputs: stroke (inches), RPM
   - Outputs: mean piston speed (ft/min), peak piston speed (ft/min)
   - Color coded: green (safe), yellow (caution), red (extreme — race only)
   - Reference table: common engine redlines and their piston speeds

4. CAMSHAFT SELECTION GUIDE (/cam-guide)
   - This is the most complex and valuable page — it does NOT pick a cam for the user, but walks them through every decision systematically with explanatory text and a filtering/comparison tool
   - Section 1: "Understanding cam specs" — explain duration, lift, LSA, ICL, overlap in plain English with visual diagrams
   - Section 2: Interactive cam profile comparison — user enters two cam specs (duration at .050, LSA, lift) and the page shows how they compare on a lobeprofile-style visual and explains trade-offs
   - Section 3: "Cam Selection Checklist" — interactive checklist form:
     * Displacement
     * Compression ratio
     * Head flow rating (CFM)
     * Intended RPM range (idle to redline)
     * Transmission type (manual/auto)
     * Torque converter stall (if auto)
     * Vehicle weight
     * Rear axle gear ratio
     * Aspiration (NA/turbo/supercharged)
     * Primary use (daily driver/weekend cruise/drag/road race)
   - Output: recommended duration range at .050", LSA range, and lift range — with a plain-English explanation of WHY those numbers fit the combo
   - Section 4: "Common mistakes" — top 10 cam selection errors with explanations
   - Section 5: Flat-tappet vs. roller cam comparison — durability, cost, break-in requirements, ZDDP oil requirements

API ROUTES (Express)
GET /api/engines — list all engine families
GET /api/engines/:slug — get full engine data + all specs
GET /api/torque-specs/search?q= — full-text search torque specs
GET /api/articles — list articles
GET /api/articles/:slug — single article
GET /api/shops — list approved shops, filterable by state and specialty
POST /api/shops/submit — submit a shop for review
POST /api/shops/:id/rate — submit a rating
POST /api/pricing/submit — submit pricing data
GET /api/search?q= — global search across all content
