## Method

- Every PDF page's text layer holds the whole two-page spread (right page repeated at x > 612 on the left page, left page at x < 0 on the right page). Spread tables are read from the left page's words so each row is one joined line; right-page-only words (series headings, footnotes) are merged in at x + 612.
- Tables are located from header lines (STROKE / LENGTH / ENGINE key cell plus header vocabulary); several tables may share a line, so each table owns an x-range. Data cells are mapped to the nearest column header; merged cells such as `SIR5400CB 525` are split by word position.
- Rotating assemblies: one record per unbalanced kit root number; the Eagle-balanced number (`B` prefix) is `spec.balancedPn` (or `balancedPns` keyed by flexplate/flywheel variant). Kits listed only in balanced form carry the `B` number as `p` with `balanced: true`. Kit numbers are root numbers: the bore suffix (`000`, `030` ...) is appended when ordering. `boreOptions` lists the bores/displacements the catalog offers the kit in; `bore` is the standard bore (page statement, cross-checked against the listed displacements, or derived from them when the page states none). `cr` is keyed by chamber cc and was calculated by Eagle at `crBore` with a `crGasket` thick gasket on an uncut block; a kit repeated on several pages with different reference bores keeps the first `cr` and gets `crByBore`.
- Series -> crank material follows the catalog's how-to page: Street & Strip = cast steel crank, Pro Street = forged 4140, Competition = forged 4340; footnoted kits (`*uses 4340 crankshaft`) are overridden; single-series import/Hemi/RB tables take the material from the table text (billet vs forged 4340, and the rod beam/material where stated). Rod type is NOT stated for the domestic multi-series kit tables and is left out.
- Cranks: material from the leading digit of the part number (1 cast steel, 5 forged 4140, 4 forged 4340, 3 billet 4340; import billet/4340 tables by heading). Main/rod journal sizes come only from page statements, journal columns, notes or main-size headings. Reluctor, long snout, 9-bolt flange, centre counterweights, rear seal come from table/column headings. `bobweight` is Eagle's 'bobweight of crank when new +/- 2%'. `minRodLength` is the catalog's minimum rod length column.
- Rods: prefix gives the line (SIR = forged 5140 I-beam per the FE/AMC kit text, FSI = 4340 I-beam per the back-cover text, CRS = forged 4340 H-beam; 3D/4D design generation, XD Extreme Duty, LW lightweight). `bigEnd` is the journal size from the `<size> JOURNAL` table label, ROD JOURNAL column or notes. Bolt grade from the part-number suffix/column (2000, L19, XD = Custom Age 625+, 4D = ARP 2000, otherwise ARP 8740); bolt diameter from the page bullet text per rod line (SIR 3/8 on small-block pages, 7/16 on big-block pages; FSI and domestic CRS 7/16; 4/6-cylinder CRS 3/8 unless noted).
- Skipped: how-to sample tables (p4-5), 4D teaser list (p6), flexplates, rear-seal adapters, spacer bearings, pilot bushings, crank machining options, rod bolts, pin bushings, alignment sleeves.

## QA (13 notes)

- p36 big-block Chevy rod table is labelled '2.100" JOURNAL' in the catalog; Eagle BBC rods are 2.200" (the catalog's own BBC crank listing on eaglerod.com gives a 2.2" rod journal) - bigEnd set to 2.2, flagged
- p46 kit 4032 SRP 41cc dome: listed 568 ci vs computed 588 at 4.560 bore x 4.500 stroke (8 cyl)
- p73 kit 2618 Traum -3.5cc flat top: listed 135 ci vs computed 132 at 3.386 bore x 3.661 stroke (4 cyl)
- p73 kit 2618 Traum 13.6cc dome: listed 135 ci vs computed 132 at 3.386 bore x 3.661 stroke (4 cyl)
- p74 kit hyper KB -27.5cc inv. dome: listed 294 ci vs computed 284 at 3.935 bore x 3.895 stroke (6 cyl)
- Kit numbers are root numbers; the bore suffix (boreOptions[].oversize or the actual bore) must be appended when ordering. One record per unbalanced root; Eagle-balanced numbers are in balancedPn/balancedPns (88 kits exist only in balanced form and carry the B number as p).
- Rod type (I-beam vs H-beam, bolts) is not stated for the domestic Street & Strip / Pro Street / Competition kit tables, so rodBeam/rodMaterial are set only where the table text names them (Hemi, RB, FE, AMC, Olds, imports).
- Crank rod-journal and main-journal sizes are recorded only where the catalog states them (page statements, JOURNAL columns, MAINS headings, notes); e.g. the SBC 305/350 and LS crank tables do not state them.
- p20-21 IMCA RaceSaver 305 kits: five kit column groups share only two header variants (3/8" ARP 2000 / 540 g rod vs 7/16" ARP 8740 / 580 g rod); what else distinguishes groups 1/3/5 is not printed - all five numbers kept.
- p38 396/402 small-bore big-block kits filed under Mark IV only (Mark IV-era engines; seal style not stated).
- p36 big-block rods and the p50-51 360-main Mopar parts are emitted under two families each (Mark IV + Gen VI; LA + Magnum per the catalog's '5.9L Magnum use 360 kits' note).
- Import rods/cranks/kits (Honda, Mitsubishi, Nissan, Subaru, Toyota, BMW, VW, Mazda, Ford/Chevy/Chrysler 4-cylinder) use the catalog heading as fit.fam with '(catalog heading)' and need a family decision.
- Rod bolt diameter comes from the page bullet text per rod line (see Method); grade from the part-number suffix. Treat bolt as B-grade data.
